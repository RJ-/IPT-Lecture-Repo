Good news

Much of this lesson will look familiar from C++ and Java. if, for, while and switch use almost the same syntax. Focus your attention on the parts marked different: truthy/falsy values, for…of, and functions as values.

2.1 Making decisions with if

Change grade to 95, then 60, and run each time. The ternary on line 12 is a compact if/else that produces a value — handy inside template literals.

Different: truthy and falsy

In Java, an if needs a real boolean. JavaScript accepts any value and treats it as true or false. Only these six values are falsy:

false   0   "" (empty string)   null   undefined   NaN

Everything else is truthy — including "0", "false", [] and {}.

Why might const qty = input || 1; be a bug if the user is allowed to type 0?

Because 0 is falsy, so 0 || 1 gives 1 — the user's real answer is thrown away. Modern JavaScript has ?? ("nullish coalescing") for this: input ?? 1 only uses the default when input is null or undefined, so 0 ?? 1 stays 0.

2.3 Functions

A function is a named, reusable set of steps. You give it inputs (parameters), it does work, and it can hand back an output with return. Unlike Java, you do not declare the types of the parameters or of the return value.

Three ways to write the same function

  • line 2 function name(params) { … } — closest to a Java method, but with no return type and no parameter types.
  • line 7 A function is a value, just like a number. You can put it in a variable.
  • line 12 Arrow function: (params) => result. If the body is a single expression, it is returned automatically — no braces, no return.

Arrow functions with a body

If you need more than one line, add braces — and then you must write return.

Why does broken(2, 3) print undefined?

Because the arrow function uses braces { }, so it has a full body — and that body never says return. A function without return gives back undefined. Fix: (a, b) => a + b (no braces) or (a, b) => { return a + b; }.

Scope: where a variable lives

let and const are block-scoped, like local variables in Java: a variable created inside { } does not exist outside it.

2.4 Functions as values (the functional style)

Here is where JavaScript really differs from older Java. Since a function is a value, you can pass a function into another function. The function you pass in is called a callback. This one idea powers button clicks (Lesson 4), waiting for data (Lesson 5), and server routes (Lesson 6).

Everyday analogy

Think of applyToAll as a class officer going down the attendance list. The officer knows how to go through the list. You hand them an instruction card (the callback): "greet each one", or "collect a contribution from each one". Same officer, different instruction card.

In Lesson 3 you will meet built-in versions of this idea — forEach, map and filter — that every JavaScript developer uses daily.

Summary

  • if/else, switch, for, while look like C++/Java.
  • Falsy values: false, 0, "", null, undefined, NaN. Everything else is truthy. Use ?? when 0 or "" are valid answers.
  • for (const x of list) loops over each item.
  • Functions: declaration, expression, arrow (a, b) => a + b. Braces mean you must write return.
  • Functions are values: you can store them and pass them as callbacks.

Which of these values is truthy?

  • 0
  • ""
  • "0"
  • null

"0" is a non-empty string, so it is truthy. The number 0, the empty string and null are falsy.

What does const label = 60 >= 75 ? "PASS" : "FAIL"; store?

  • "FAIL"
  • "PASS"
  • false
  • undefined

The condition is false, so the ternary picks the value after the colon.

Which loop is the cleanest way to print every item in const fruits = ["pili", "mango"]?

  • while (fruits) { … }
  • for (fruits) { … }
  • for (let f in 10) { … }
  • for (const f of fruits) { console.log(f); }

for…of visits each item of an array directly, without an index.

What does const add = (a, b) => { a + b; }; add(1, 2) return?

  • 3
  • undefined
  • "12"
  • an error

With braces the arrow function has a body and needs an explicit return. Without it, the result is undefined.

A function that is passed into another function, to be called later, is called a…

  • constructor
  • constant
  • callback
  • class

A callback is a function handed to another function, which "calls it back" when needed — on each item, on a click, or when data arrives.

A user is allowed to enter 0 for "number of absences". Which line keeps their 0 instead of replacing it with a default of 3?

  • const a = input || 3;
  • const a = input ?? 3;
  • const a = !input;
  • const a = input && 3;

?? only falls back when the value is null or undefined. || also replaces 0, because 0 is falsy.
