How to use this module

  1. Read it like a lecture. Each lesson is written the way I would explain it in class: a question to answer, short explanations, everyday examples, and code explained one line at a time.
  2. Go in order. Each lesson builds on the one before. Lessons 1–3 are the language itself; Lessons 4–5 are the browser; Lessons 6–8 are integration — the heart of IPT1.
  3. Press ▶ Run on every "Try it" box. Then change something and run it again. Breaking the code on purpose is one of the fastest ways to learn. The Reset button brings the original back.
  4. Stop at every Pause and Think box. Try to answer in your head (or on paper) before you tap to reveal.
  5. Answer the Check Yourself quiz at the end of each lesson, then press Mark lesson complete. Your progress is saved in this browser.
On a phone?

Everything works on a phone. Turn it sideways for the longer code boxes. To run code faster on a computer, press Ctrl + Enter inside a code box.

Lessons

What you will be able to do

  • Read and write basic JavaScript: variables, types, conditions, loops, functions, arrays and objects.
  • Explain why JSON is the common language that lets different systems exchange data.
  • Make a web page respond to the user by changing the DOM with JavaScript.
  • Use async/await and fetch() to get data from an API without freezing the page.
  • Build a small REST API with Node.js and Express.
  • Connect a front end to a back end, and explain and fix a CORS error.
  • Recognise how JavaScript implements the other IPT1 topics: WebSockets, databases, cross-platform mobile apps, microservices, serverless functions, WebAssembly and CI/CD.
