Glossary

Key terms from the module, in alphabetical order. The number in brackets is the lesson where the term is explained.

API (Application Programming Interface) [5]
A defined way for one program to ask another for data or actions. A web API answers HTTP requests, usually with JSON.
Array [3]
An ordered list of values, e.g. [85, 92, 78]. Indexes start at 0.
Arrow function [2]
A short way to write a function: (a, b) => a + b.
async / await [5]
Keywords that let asynchronous code read top to bottom. await pauses an async function until a Promise settles.
Asynchronous [5]
Work that is started now and finished later (network, timers, databases) without blocking other code.
Callback [2]
A function passed to another function, to be called later — on each item, on an event, or when data arrives.
CI/CD [8]
Continuous Integration / Continuous Deployment: automatically testing (and then publishing) code on every change.
const / let [1]
Ways to declare variables. const cannot be reassigned; let can. Avoid the older var.
CORS (Cross-Origin Resource Sharing) [7]
The browser rule that a page may only read responses from another origin if that server sends Access-Control-Allow-Origin. Fixed on the server.
CRUD [6]
Create, Read, Update, Delete — the four basic data operations, matching POST, GET, PUT/PATCH and DELETE.
DOM (Document Object Model) [4]
The tree of objects the browser builds from HTML, which JavaScript can read and change.
Endpoint [6]
A specific method + path an API responds to, e.g. GET /api/students.
Environment variable [8]
A setting supplied from outside the code (process.env.DB_PASS), used to keep secrets out of source files.
Event / event listener [4]
Something that happens (click, submit, message) and the callback registered with addEventListener to handle it.
Express [6]
The most popular Node.js framework for building web servers and REST APIs.
fetch() [5]
The built-in function for sending HTTP requests from JavaScript. Returns a Promise of a response.
GraphQL [7]
An API style with one endpoint, where the client's query states exactly which fields it wants.
HTTP status code [5]
A number in every response: 2xx success (200, 201, 204), 4xx client error (400, 404), 5xx server error (500).
JSON [3]
JavaScript Object Notation — a plain-text data format every language can read. JSON.stringify to send, JSON.parse to receive.
map / filter / reduce [3]
Array methods that transform, keep, or combine items using a callback.
Microservices [8]
An architecture of small, independent services that each own one job and communicate through APIs.
Middleware [6]
A function in Express that runs before routes, receives (req, res, next), and either responds or calls next().
Node.js [6]
A runtime that executes JavaScript outside the browser, used for servers, tools and scripts.
npm / package.json [6]
Node's package manager, and the file that lists a project's dependencies and scripts.
Object [3]
A collection of named properties, e.g. { name: "Ana", grade: 91 }.
Origin [7]
Protocol + host + port, e.g. http://localhost:3000.
Promise [5]
An object representing a future value; it is pending, then fulfilled or rejected.
React / React Native [7, 8]
A library for building user interfaces from components and state; React Native uses the same approach for Android and iOS apps.
req.params / req.query / req.body [6]
Data from the URL path, from the query string after ?, and from the request body (needs express.json()).
REST [6]
A style of API design: resources as nouns in URLs, HTTP methods as verbs, JSON as the format.
Same-origin policy [7]
The browser security rule that limits how a page can read data from other origins.
Serverless [8]
Running individual functions in the cloud on demand (e.g., AWS Lambda), without managing a server.
SQL injection [8]
An attack where input changes a database query. Prevented with placeholders (?).
Template literal [1]
A backtick string with embedded expressions: `Hi ${name}`.
Truthy / falsy [2]
How values behave in conditions. Falsy: false, 0, "", null, undefined, NaN; everything else is truthy.
WebAssembly (Wasm) [8]
A binary format for fast code compiled from languages like C++ or Rust, loaded and called from JavaScript.
WebSocket [8]
A protocol that keeps a two-way connection open so the server can push data in real time.
XSS (Cross-Site Scripting) [4]
An attack where user-supplied text is run as code on a page. Prevented by displaying user text with textContent.
