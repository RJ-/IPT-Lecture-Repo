Arrays, Objects & JSON

Real systems move records around — students, orders, readings from a sensor. How does JavaScript hold them, transform them, and send them to another system?

3.1 Arrays: ordered lists

An array holds many values in order. Unlike a Java array, a JavaScript array can grow and shrink (it behaves more like Java's ArrayList), and it can even mix types.

const and arrays

const scores = [...] means the label scores always points to the same array. You can still push into it or change its items. What you cannot do is scores = [1, 2] (point the label at a different array).

3.2 Objects: one record with named fields

An object groups related values under property names (also called keys). In Java you would write a whole class for this; in JavaScript you can just write the object directly with curly braces.

When would you need bracket notation student[key] instead of student.key?

When the property name is stored in a variable, or has a space or dash in it. For example, const field = "name"; console.log(student[field]); reads student.name. Writing student.field would look for a property literally called "field".

Objects can hold functions (methods)

This is JavaScript's object-oriented side. A function stored in an object is called a method; inside it, this refers to the object.

JavaScript also has class syntax that will feel familiar from Java (class Student { constructor(name) { this.name = name; } }). We will not need it in this module, but you will see it in frameworks.

3.3 Arrays of objects — the shape of real data

A list of students, a list of orders, a list of posts: almost every API returns an array of objects. Learn to read this shape at a glance.

3.4 Transforming data: forEach, map, filter, find, reduce

Remember callbacks from Lesson 2? Arrays come with built-in methods that take a callback and apply it to every item. This is the functional style: instead of writing a loop and a temporary variable, you describe what you want.

Rewrite students.filter(s => s.grade >= 75) as a regular for…of loop. Which version is easier to read?

Both work. The filter version says what you want in one line; the loop says how to do it step by step. Professional JavaScript code — and frameworks like React — strongly favour map and filter.

3.5 JSON — the common language of integration

Here is the integration problem: a JavaScript front end has a students array. It needs to send it to a server that might be written in Python, PHP, Java or C#. Those languages cannot read JavaScript objects directly. They need a text format that every language understands.

That format is JSON — JavaScript Object Notation. It looks almost exactly like a JavaScript object, but it is plain text, with a few stricter rules:

  • Property names must be in double quotes: "name".
  • Strings use double quotes only.
  • Allowed values: string, number, true/false, null, arrays, objects. No functions, no undefined, no comments.

Everyday analogy

A JavaScript object is like furniture assembled in your room. You cannot ship it through a narrow door, so you flat-pack it into a box with instructions (JSON.stringify). The receiver — who may speak a different language, but reads the same standard instructions — assembles it again (JSON.parse).

A Python back end receives {"grade": "91"} and another receives {"grade": 91}. Are these the same data?

No. In the first, grade is a string; in the second, it is a number. JSON keeps the type. Teams that integrate systems agree on a data contract — the exact field names and types — so both sides read the data the same way.

Summary

  • Arrays are ordered, growable lists: push, pop, length, includes.
  • Objects are records with named properties; read them with obj.key or obj[key].
  • Real data is usually an array of objects.
  • map transforms, filter keeps, find picks one, reduce combines, forEach just does.
  • JSON is text that any language can read. JSON.stringify to send, JSON.parse to receive.

Given const s = ["a", "b", "c"], what is s[1]?

  • "a"
  • "b"
  • "c"
  • undefined

Indexes start at 0, so index 1 is the second item.

Which method returns a new array of the same length with each item transformed?

  • filter
  • find
  • forEach
  • map

map transforms every item and returns a new array with the same number of items.

What does [5, 80, 92, 60].filter(n => n >= 75) return?

  • [80, 92]
  • [5, 60]
  • 80
  • true

filter keeps every item for which the callback returns true.

Which of these is valid JSON?

  • {name: "Ana"}
  • {'name': 'Ana'}
  • {"name": "Ana", "grade": 91}
  • {"name": "Ana", greet() {}}

JSON requires double-quoted property names and strings, and cannot contain functions.

Your front end must send an object to a Java server. Which call turns the object into text first?

  • JSON.parse(obj)
  • JSON.stringify(obj)
  • obj.toJSON()
  • String.parse(obj)

stringify converts an object to JSON text for sending; parse does the reverse on the receiving side.

Why is JSON so important in integrative programming?

  • It makes JavaScript run faster.
  • It can only be read by JavaScript, which keeps data safe.
  • It stores data in a database automatically.
  • It is a plain-text format that systems written in different languages can all read and write.

JSON is language-neutral text. That makes it the default format for APIs that connect different systems.
