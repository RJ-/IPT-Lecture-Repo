With your group, build a small system in which a front end and a back end exchange JSON through a REST API. Choose one theme (or propose your own to me):

Required features

  1. GET — list all records, shown on the page.
  2. POST — add a record from a form; the server answers 201 with the new record.
  3. DELETE (or PUT for Theme C) — remove or update a record by id; answer 404 if it does not exist.
  4. Server-side validation — reject missing or invalid fields with 400 and a clear error message.
  5. Front-end feedback — show loading, success and error messages to the user.
  6. Safe rendering — user-typed text is displayed with textContent.
